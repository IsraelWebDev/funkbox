# funk v1 and v2 reference

CPU-only procedural art: seamless looping **MP4 / GIF / PNG** from math, not models.
No GPU, no accounts, no API keys, no credits. Usable from the command line or by Claude over MCP.

## Setup (Windows)

```powershell
cd C:\dev\funkbox
powershell -ExecutionPolicy Bypass -File .\setup.ps1 -Register
```

That creates a `.venv`, installs numpy / Pillow / a bundled ffmpeg / the MCP SDK, renders a smoke test,
and adds a `funk` server to Claude Desktop's config (a timestamped backup of the config is written first).
Restart Claude Desktop afterwards.

Claude Code instead:
```
claude mcp add funk -e FUNK_OUT=C:\dev\funkbox\out -- C:\dev\funkbox\.venv\Scripts\python.exe C:\dev\funkbox\funk_mcp.py
```

## CLI

```
python funk.py list                                         # presets, effects, palettes, keys
python funk.py sheet  --preset hypno-tunnel --seeds 1-9     # pick a variation
python funk.py sheet  --random --seeds 1-12 --cols 4        # roll whole random recipes
python funk.py render --preset liquid-disco --seed 7
python funk.py render --random --seed 5 --text "FUNK WAS HERE"
python funk.py render --preset lava-lamp --set palette=toxic kaleido=6 chroma=5
python funk.py render --recipe out/hero-sun-mandala.json    # reproduce anything exactly
```

Every render writes `<name>.json` next to the media with the full recipe, seeded params included,
so a look you like is never lost. Defaults: 540x540, 30 fps, 4 s.

## MCP tools

| tool | use |
|---|---|
| `list_looks` | presets, effects, palettes, override keys |
| `preview_still` | one frame, fast. Iterate on the look here |
| `contact_sheet` | grid across seeds to choose a variation |
| `render_loop` | the real MP4 + GIF + PNG + JSON |

Each tool returns a PNG preview with its text, so Claude sees the result and can critique it
("too busy, drop halftone, push chroma") instead of rendering blind.

Try: *"Use funk to make a 6-second 720px loop for a party invite: something hypnotic and warm,
with the text SHABBAT PARTY. Show me 6 options first."*

## Knobs

| key | effect |
|---|---|
| `effect` | plasma, moire, warp, tunnel, blobs, rings |
| `palette` | acid, vapor, sunset, toxic, candy, ice, mono |
| `cycles` | palette rotations per loop (int) |
| `spin` | rotations per loop (int, negative = counter-clockwise) |
| `zoom` | breathing zoom amplitude (0.1–0.3) |
| `kaleido` | mirror segments (4, 6, 8...) |
| `posterize` | colour levels (5–10 = screenprint) |
| `halftone` | dot cell size in px (pop-art) |
| `chroma` | RGB split px (pulses with the loop) |
| `scanlines`, `vignette`, `grain` | CRT dressing |
| `text`, `text_size`, `text_wobble`, `text_color`, `shadow` | wavy title; auto-fits width, `\n` for line breaks |

## Why the loops are seamless

Time enters every effect only as `theta = 2*pi*t`, always multiplied by an integer. Frame N is
therefore frame 0, and is pixel-identical to it except for grain. Two float traps are handled:

- Palette phase is reduced mod 1 *before* time is added, so large field values keep precision.
- The tunnel's `sign()` edges are nudged off the exact symmetry diagonals, where `sin(0)` vs
  `sin(2*pi) = -2e-16` would otherwise flip pixels between the first and last frame.

## Adding an effect

```python
@effect("spiral", "log spiral arms",
        lambda r: {"arms": int(r.integers(2, 7))})
def _spiral(u, v, th, p):
    r, a = np.hypot(u, v) + 1e-3, np.arctan2(v, u)
    return 0.5 + 0.5 * np.sin(p["arms"] * a + 6 * np.log(r) - 2 * th)
```

Keep every use of `th` multiplied by an integer and the loop stays seamless.
The sampler gets a seeded `np.random.Generator`, which keeps runs reproducible.

# funk v2: GPU shader engine

v2 keeps v1 untouched (`funk.py`, `funk_mcp.py`) and adds a GPU engine in `funkgl/`: Claude writes GLSL
fragment shaders, gets compiler errors (in its own line numbers) and a PNG back over MCP, composes shaders,
images and v1 effects as layers with blend modes, post passes and text, and renders **machine-checked
seamless loops**. On the target laptop (Iris Xe, GL 3.3) a 1080x1080 frame renders and reads back at ~74 fps,
about 100x v1.

## Quickstart

```
pip install -r requirements.txt       # now includes moderngl>=5.10
python funk2.py info                                      # GL renderer/version + shader list
python funk2.py check  shaders/plasma.frag                # compile + loop check, exit 1 on failure
python funk2.py sheet  --shader shaders/voronoi_pop.frag --seeds 1-9 -o out/vp.png
python funk2.py still  --recipe examples/disco_cat.json --t 0.25 -o out/x.png
python funk2.py render --shader shaders/plasma.frag --palette vapor --post chroma=4 grain=0.03
python funk2.py render --recipe examples/disco_cat.json --size 720 --seconds 6   # add --gif for a GIF too
python funk2.py port-v1                                   # rewrite the six shaders/*.frag v1 ports
```

On a headless Linux box set `FUNK_GL_BACKEND=egl` (Mesa llvmpipe works, slowly). On Windows leave it unset.
`render` runs the loop check first and refuses a broken loop (`--no-check` to override). Every render writes
`<name>.json`: a v2 recipe with the shader source inlined, so it reproduces the render even if the `.frag`
changes later (`python funk2.py render --recipe out/<name>.json`). v1 sidecar JSONs load too.

## Shader contract

User shaders are fragment shaders **without a `#version` line**; define `vec4 effect(vec2 p)` (p = `uv()`)
or Shadertoy's `void mainImage(out vec4 fragColor, in vec2 fragCoord)`.

| name | type | meaning |
|---|---|---|
| `iResolution` | vec3 | (width, height, 1.0) |
| `iLoop` | float | loop position t in [0, 1) |
| `iPhase` | float | 2*pi*t. **The only sanctioned way to animate: always multiply it by an integer** |
| `iTime` | float | t * seconds. Shadertoy compat; **breaks loops** |
| `iFrame` | int | frame index |
| `iSeed` | float | the seed, for per-variation offsets |
| `iChannel0` | sampler2D | everything composited below this layer (post passes: their input) |
| `iChannel1..3` | sampler2D | images listed in the layer's `channels`; with audio, `iChannel3` is the 512x1 log spectrum |
| `iAudio` | vec4 | (bass, mid, treble, level) 0..1 for this frame; zeros without audio |
| `uv()` | vec2 | centred coords, short side spans [-1, 1], **+y points up** |
| `palette(x)` | vec3 | the recipe palette; rotates `cycles` times per loop |
| `pal(x,a,b,c,d)` | vec3 | Inigo Quilez cosine palette |
| `loopNoise(p, r)` | float | 2D simplex noise that loops exactly (circle of radius r in 4D noise) |
| `snoise2/3/4` | float | ashima/webgl-noise simplex noise (MIT) |
| `rot(p,a)`, `wrap01(x)`, `src0(p)` | | rotate; fract; sample `iChannel0` at centred coords |

Parameters: `uniform float u_freq; // @param 2.0 9.0 4.0` (min max default), `uniform int u_arms; // @param 2 8 5`,
`uniform vec3 u_tint; // @param color #ff2bd6`. The recipe seed samples floats/ints in declaration order;
explicit recipe `params` win. **Name integer multipliers of `iPhase` `k_*`** (a non-integer one breaks the loop).
Opt out of the automatic loop test with a `// @noloopcheck` comment (used by `feedback_echo.frag`, which loops
only if the layers beneath it do). Fix a failing loop in the shader; never loosen the checker.

Bundled: `plasma moire warp tunnel blobs rings` (ports of the v1 effects) and `fbm_flow voronoi_pop
raymarch_blob feedback_echo` (GPU-only looks).

## Recipe (JSON)

```json
{
  "version": 2,
  "settings": {"width": 720, "height": 720, "fps": 30, "seconds": 4, "seed": 7},
  "palette": {"name": "vapor", "cycles": 1},
  "layers": [
    {"type": "shader", "shader": "shaders/warp.frag", "params": {"u_amp": 0.4}},
    {"type": "image", "path": "cat.png", "fit": "contain", "blend": "screen", "opacity": 0.8, "uv_warp": 1.0},
    {"type": "v1", "effect": "blobs", "blend": "add", "opacity": 0.5}
  ],
  "post": [{"name": "chroma", "px": 4}, {"name": "grain", "amount": 0.03}],
  "text": {"text": "FUNK", "size": 0.13, "wobble": 6, "color": "#ffffff", "shadow": "#ff2bd6"}
}
```

Blend modes: `normal add screen multiply overlay difference softlight hue`. Post passes: `chroma halftone
posterize scanlines vignette grain`. Relative paths resolve against the recipe's folder, then `FUNK_HOME`;
**files must live inside `FUNK_HOME`, `FUNK_OUT` or `FUNK_INPUTS`** (drop your images in `inputs/`). Optional
`"audio": "song.wav"` in `settings` (PCM WAV) drives `iAudio`/`iChannel3`, defaults `seconds` to the clip
length, is muxed into the mp4, and skips the loop check (audio loops are not seamless unless the music is).
`examples/disco_cat.json` is a runnable sample; `python examples/make_cat.py` regenerates its image.

## MCP server (`funk2_mcp.py`)

```
claude mcp add funk2 -e FUNK_OUT=C:\dev\funkbox\out -- C:\dev\funkbox\.venv\Scripts\python.exe C:\dev\funkbox\funk2_mcp.py
```

| tool | args | returns |
|---|---|---|
| `gl_info` | | renderer, version, shader names, folders |
| `list_looks` | | v2 shaders with `@param` ranges, post passes, blend modes, layer types, v1 presets/effects/palettes |
| `write_shader` | `name, source, check=True` | compile result with **your** line numbers + loop report + a 384px still; saves `shaders/<name>.frag` only if it compiles (and loops) |
| `get_shader` | `name` | source text |
| `preview` | `recipe, t=0.25, size=448` | resolved-recipe summary + PNG |
| `contact_sheet` | `recipe, seeds="1-6"` | PNG (<=900px wide) + saved path |
| `render` | `recipe, name="", gif=False` | paths, timing, loop report, poster. GIF is opt-in (≈10x slower than the mp4 on busy loops). Limits: <=1080px, <=20 s, <=60 fps |
| `render_v1` | v1 `render_loop` args | delegates to the CPU v1 engine |

Tools never raise: failures come back as a readable `ERROR: ...` string. Nothing is ever printed to stdout.
